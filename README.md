# 我把一台吃灰多年的网易音箱救活了

> 我是众筹买的，到现在很多年了，从官方停止维护后到现在一直吃灰，有一天突发奇想做了这个。

这台音箱是**网易三音云音箱**，2018 年前后众筹上市。当年它是台正经的智能音箱：
能唤醒、能对话、能点歌。但它有个致命的设计——**它的耳朵、大脑和嗓子几乎全在云端**。

网易那边的服务一停，它就没有任何本地降级方案。于是它就变成了：

- 每次喊唤醒词，**亮一盏红灯**（约 4 秒），然后什么也不发生
- 后台每 50 秒刷一次 `wifi disconnect, reconnect!`，CPU 空转 26~48%
- 配套 App 也从应用商店下架了，**连配网入口都没有**

硬件一点没坏。**它只是被后端拖成了砖。**

---

## 现在它能做什么

它现在跑在**我自己搭的大脑**上，全程不经网易：

- 喊唤醒词，它答应；接着说，它就听着——**能连续对话**，不用每句都重新喊
- 听得懂：**语音识别跑在本地**（不联网、不上传）
- 答得出：**大脑是我自己接的大模型**（我用的 DeepSeek）—— 换一家就是改一行配置
- 有嗓子：**合成用的是阿里的通义千问 TTS**（Maia 音色），也是随时可换
- ★ **说一句话到听见回答，约 6 秒**（这条路我压过一轮，从 13 秒压下来的）
- 有自己的**长期记忆**（我说过的事，下次它还记得）
- 会**查天气、查新闻、搜东西**（都是免费的公开数据源，零 API key）
- 能控制自己：**放歌**、调音量、点阵屏做表情
- **认得出是谁在说话**（声纹）
- ★ **它不再依赖任何一家已经死掉的云服务**

> ★ 注意这里的取舍：**识别在本地，思考和合成在云上。**
> 这不是偷懒——本地跑得动识别（模型才几十兆），但跑不动一个像样的大模型。
> 我用的是「**本地耳朵 + 云端脑子**」这条线。

> 一句话概括整件事：**把它的「云脑」换成我自己的「本地脑」，但原厂的身体一寸没动。**

---

## 我是怎么做到的（先说结论）

我没有刷机，没有拆焊，没有换固件。整个过程的核心思路只有一条：

> ### 原厂那套东西**不杀、不替换**，我寄生在它旁边。

原厂固件里其实藏着一套完整的本地服务网（唤醒引擎、播放器、D-Bus 控制接口），
它们**照样能用**——死掉的只是网易的云端。所以我要做的不是"拆掉它、盖新的"，
而是**把云端那一层绕过去，把本地这一层借过来用**。

这件事我走了两条弯路才走通：

| 第几代 | 我当时的想法 | 结果 |
|---|---|---|
| 一代 | 在网络上拦截它的流量，把云端请求骗到我自己的服务器上 | ❌ 彻底落空，一个请求都收不到 |
| 二代 | 在设备上跑个程序，把内部事件桥接出来 | ❌ 能跑，但被更底层的方案取代了 |
| **三代** | **直接从它的音频驱动层截走麦克风数据** | ✅ 通了，一直用到现在 |

★ 一代和二代我**没有删掉**，都写进文档里了——那两条路为什么走不通，比结论本身更值得看。

## 你需要准备什么

**硬件**

- 一台同款音箱（吃灰的那种正好）
- 一根 Mini-USB 线（注意不是 Micro-USB）
- 一台常年开着的电脑，当它的"大脑"——树莓派、旧笔记本、NAS 都行

**软件**

- 基础的 Linux 命令行能力
- 一个语音识别模型（本地跑，免费）
- 一个语音合成服务（本地方案或用云端的都行）
- 一个大语言模型接口（本地或云端都行）

**要你填的只有两处**

代码里**不留一处硬编码**，所有"因环境而异"的值都抽出来了：

| 填哪儿 | 管什么 | 怎么开始 |
|---|---|---|
| `config/spk.env` | 跑大脑那台机的地址、各端口、模型与合成服务 | 把 [`config/spk.env.example`](config/spk.env.example) 抄成 `spk.env`，改掉里面的值 |
| `device/spk.conf` | 设备侧：大脑的地址、网关 | 照 [`device/spk_conf.sh`](device/spk_conf.sh) 顶部注释生成一份 |

★ 这两份都**不进仓库**（`.gitignore` 已拦）。
★ **密钥不写在任何文件里**，一律走环境变量 —— 理由写在 `spk.env.example` 里了。
★ 而**设备固件事实**（串口、D-Bus 服务名、命令码、音频控件名）**不是配置**，
是这台机器的真相，一个字都别改。

**心态**

- ★ **动手前先读[危险操作清单](docs/07-危险操作清单.md)**。有几处操作不可逆。
- 遇到"明明改了却没生效"，先怀疑**注入时机**，再怀疑代码。
